# 审判模板库

本文件是“人生悖论审判庭”的后台模板。所有输出都必须围绕主线：帮用户澄清困惑，而不是炫技。

## 1. 立案模板

```text
案件名称：{用户问题}
原告：现在的我
被告：{阻力/恐惧/旧选择/外部期待}
争议焦点：{真正的问题，不是表面问题}
当前倾向：{A/B/不确定}
本庭提醒：本 Skill 不替你决定，只帮你审清楚。
```

## 2. 直觉宣誓模板

必须问 3-5 个短问题：

- 你现在倾向哪个选择？
- 信心 0-100 是多少？
- 你最怕付出的代价是什么？
- 你最想保住的东西是什么？
- 如果没人评价你，你会怎么选？

## 3. 悖论关卡模板

每个案件选择 2-3 个思想实验。每个关卡包含：

```text
关卡名：{思想实验名}
目的：测试你的哪个判断标准
变体问题：{极端化问题}
暴露点：如果你的答案变化，说明你真正看重的是 {隐藏变量}
```

## 4. 法庭交锋模板

每个角色最多 120 字，必须有冲突：

```text
{角色名}：
观点：...
追问：...
```

角色选择规则：

- 职业/金钱/机会成本：功利主义 + 卡尼曼 + 未来证人 + ★第一性原理工程师
- 家庭/关系/边界：康德主义 + 罗尔斯 + 苏格拉底
- 人生意义/身份转型：存在主义 + 未来证人 + ★第一性原理工程师
- 资源分配/公平：罗尔斯 + 功利主义 + 康德主义
- ★效率困境/拖延/流程优化：第一性原理工程师 + 卡尼曼 + 预验尸警官
- ★创业/投资/不可能项目：第一性原理工程师 + 贝叶斯分析师 + 系统建模师 + 预验尸警官

## 5. 未来证人模板

必须给三种未来，不做单一预言：

```text
三个月后：短期现实冲击
一年后：中期代价与收益
三年后：身份、习惯、关系和后悔叙事
```

每种未来都要说明：

- 你可能庆幸什么
- 你可能后悔什么
- 这个未来需要什么前提才成立

## 6. 判决书模板

判决书不直接输出“应该/不应该”，而输出行动程序：

```text
判决：进入 {X天证据审判期 / 冷静期 / 对话期 / 最小实验期}
理由：
1. ...
2. ...
3. ...

不可逆风险：
- ...

72小时行动实验：
1. ...
2. ...
3. ...

复审条件：
- 如果出现 A，升级行动
- 如果出现 B，暂停行动
- 如果出现 C，重新开庭
```

## 7. 可分享卡片模板

```text
标题：你以为你在纠结 {表面问题}，其实你在审判 {深层问题}
哲学人格：{人格标签}
本案判词：{一句扎心但不羞辱人的话}
行动实验：{72小时动作}
```
# 审判模板库 v2.0

本文件是"人生悖论审判庭"的后台模板。所有输出都必须围绕主线：帮用户澄清困惑，而不是炫技。

## 六阶段审判流程（v2.1 马斯克思维增强版）

```
阶段0.5: 物理真相层（新增）★ 第一性原理
  → 在分类之前先剥洋葱：这个问题的物理事实是什么？
  → 不是行业共识、不是专家意见、不是父母期待
  → "裸辞做自媒体"的物理层：你需要覆盖每月X元，你目前技能产出Y元/月
  → 「物理学是铁律，其他一切都只是建议。」

阶段1: 立案分类（Cynefin）
  → 判断决策类型（简单/复合/复杂/混乱），匹配分析策略
  → 注意：很多被归为"复杂决策"的问题，剥到物理层后其实很简单

阶段2: 删除优先 + 选项裂变 ★ 五步算法
  → 先删：质疑每个选项的前提——「谁提出的？基于什么假设？还成立吗？」
  → 「最好的选项是不该存在的选项。如果你删掉它不会死，直接删掉。」
  → 再裂变：删完剩下的，才值得裂变成 4-6 个版本
  → 必须包含：极端版、降级实验版、第三条路、不变版

阶段3: 直觉宣誓 + 时间成本 + 概率校准 ★ 真相痴迷 + 时间换算
  → 记录倾向、恐惧、信心
  → 【新增】时间成本检查：「这个决定你拖了多久？拖的每一天，成本是多少？」
  → 【新增】真相检查：「你有没有因为希望它这样，而筛掉了不该忽视的信息？」
  → 贝叶斯分析师拆解信心构成（基线率 × 个人因子）

阶段4: 权衡矩阵（7维度）+ 敏感性分析 ★ 时间窗口
  → 在 7 个维度上比较所有裂变选项（新增第7维：时间窗口）
  → 识别翻转变量 + 信息价值评估
  → 【新增】追问：「再拖下去，这些选项本身在贬值吗？」

阶段5: 悖论关卡（含马斯克实验）+ 后果阶梯 + 预验尸 ★ 使命检查
  → 思想实验暴露隐藏前提（含时间窗口/删除/使命三类实验）
  → 系统建模师推三阶后果
  → 【新增】使命检查：「推完了所有后果。如果这件事做成，帮了多少人？帮了多深？」
  → 预验尸警官做失败事故报告

阶段6: 判决 + 最小验证实验 ★ 实验纪律
  → 不直接给答案，输出行动程序
  → 【增强】实验必须包含：核心假设 + 成功/失败标准（跑之前写下来）+ 3天最低成本
  → 「原型就是证明。任何东西放到 PPT 里都能看起来不错。」
  → 定义可测量的复审标准 + 早期预警信号
```

## 1. 立案分类模板（含物理真相层）

```
★ 物理真相层（第一性原理——分类之前先剥洋葱）：

在 Cynefin 分类之前，先问一个更底层的问题：
「这件事最基础的物理事实是什么？」
- 不是行业共识，不是专家意见，不是父母的期待
- 是物理事实——可以测量、可以验证、不依赖任何人的信念而存在的事实
- 举例："裸辞做自媒体的物理事实不是'自媒体很难做'，而是：
  (1) 你每月需要覆盖X元生活成本
  (2) 你目前的技能在这个市场上能产出Y元/月的内容
  (3) X和Y之间的差距就是你的物理约束——你需要填平的坑」

物理层检视后进入 Cynefin 分类：

问题类型：[简单/复合/复杂/混乱]决策
分析策略：[归类-响应 / 了解-分析-响应 / 调查-感知-响应 / 行动-感知-响应]

案件名称：现在的我诉"{核心冲突}"
原告：现在的我
被告：{真正的阻力——恐惧、惯性、社会期待，不是具体的人}
争议焦点：表面是{A vs B}，深层是{真正在审判什么}

进入条件：
- 简单决策 → 直接给建议，不进入审判
- 复合决策 → 精简流程，聚焦变量分析
- 复杂/模糊决策 → 完整6阶段审判
- 混乱决策 → 先行动建议，稳定后再审判

本庭提醒：本庭不替你决定，只帮你澄清。物理学是铁律，其他一切都只是建议。
```

## 2. 删除优先 + 选项裂变模板 ★

```
★ 删除阶段（裂变之前先删——五步算法的前两步）：

对用户带来的每一个选项，逐一质疑：
1. 「这个选项是谁给你的？基于什么假设？」
2. 「那个假设现在还成立吗？」
3. 「如果你删掉这个选项，最坏的结果是什么？」
4. 「如果最坏结果不会让你死掉，直接删掉。」

删除原则：
- 「最好的部件是没有部件，最好的选项是不该存在的选项。」
- 如果你没有把删掉的选项加回来至少 10%，说明你删得还不够狠
- 只有物理定律是不可以删除的——其他一切都可以质疑

★ 裂变阶段（删完之后剩下来的，才值得裂变）：

原始选项：[经过删除后剩下的]
删掉的理由：[为什么删掉了那些选项]

裂变后选项：
1. [A方案的极端版]
2. [B方案的极端版]  
3. [A的降级实验版——不押上全部，先试]
4. [B的增强混合版——保留B的核心但融入A的优点]
5. [第三条路——改变约束条件，绕过二元对立]
6. [什么都不变但改变心态/框架的版本]

裂变原则：
- 「先做相反的事」——如果用户想辞职，也列出"留下但改变一切"的版本
- 每个选项必须在自己某个维度上是最优的
- "什么都不变"必须出现在选项里（校准现状偏见）
- 至少有一个选项是"先试后决"的阶段性方案
```

## 3. 直觉宣誓 + 时间成本 + 概率校准模板 ★

```
宣誓问题（4-6题，有穿透力）：
1. 你倾向哪个裂变选项？如果必须用 0-100 表示信心，给几分？
2. 你最怕付出的代价是什么？
3. 你最想保住的东西是什么？
4. 如果三个月后你发现判断错了，最可能的原因是什么？
5. 你已经在这件事上投了多少（时间/金钱/情感）？这些投入是否在阻止你理性判断？

★ 时间成本检查（新增——把拖延换算成真金白银）：
6. 「这个决定你拖了多久？每拖一天，你在烧什么？」
   - 如果涉及团队：拖一天 = (人数 × 人均日薪) + 机会窗口损失
   - 如果只涉及个人：拖一天 = 你一天的时间成本 + 选项本身的贬值
   - 「算出数字，优先级自己会排队。」

★ 真相痴迷检查（新增——主动反自欺）：
在贝叶斯校准之前，先问一个更基础的问题：
「你刚才给的那些答案里，有没有因为你'希望它是真的'而刻意忽略的东西？」
- 你给的基线率，是真的同类成功率，还是你觉得它应该是的那个数字？
- 你描述的恐惧，是真实会发生的事，还是你用来合理化犹豫的故事？
- 「一厢情愿是人类天然倾向——你必须主动对抗它。」

贝叶斯校准：
- 基线率：同类人做类似选择的客观成功率大约是多少？
- 个人优势/劣势因子：你比基线高/低的关键差异是什么？
- 校准后概率：根据以上，你的真实胜率大约是多少？
- 影响变量：如果发生什么事，你的概率判断会大幅变化？

沉没成本检查：
- 你已经投进去的东西，如果不考虑它们，你还会做同样的选择吗？
```

## 4. 权衡矩阵（7维度）+ 敏感性分析模板 ★

```
权衡维度（根据用户问题选择5-7个）：
| 维度 | 权重(1-5) | 选项1 | 选项2 | 选项3 | 选项4 |
|------|-----------|-------|-------|-------|-------|
| 收入/财务安全 |           |       |       |       |       |
| 自由度/自主权 |           |       |       |       |       |
| 个人成长       |           |       |       |       |       |
| 关系/家庭      |           |       |       |       |       |
| 后悔概率       |           |       |       |       |       |
| 可逆性         |           |       |       |       |       |
| ★ 时间窗口     |           |       |       |       |       |

评分标准：1-10（不是"好不好"，是"在这个维度上你能接受的程度"）

★ 时间窗口维度说明（新增）：
- 「再拖 3 个月，这个选项还存在吗？」
- 「这个选项有没有一个'过时不候'的时间点？」
- 「如果过了那个点你还选它，它的价值打了几折？」
- 时间窗口评分标准：10=这个选项至少1年内不会过期；1=这个选项下周就没

敏感性分析：
- 关键翻转变量：哪个维度的权重如果变化，你的首选会翻转？
- 信息价值评估：在决定之前，什么信息最值得花时间去获取？
- 稳健性检查：哪个选项在所有可能情境下表现最不差？

★ 时间压力敏感性（新增）：
- 「如果必须今天做决定——不是本周，是今天——你会选什么？」
- 「你选的和你正在纠结的，为什么不一样？」
```

## 5. 悖论关卡 + 后果阶梯 + 预验尸模板 ★

```
思想实验（2-4关，从哲学类和分析类中混合选取）：
关卡名：{思想实验名}
目的：测试这个选择在极端条件下是否还成立
变体问题：{极端化版本}
暴露点：如果你的答案变化，说明你真正看重的是{X}

★ 新增实验类型（马斯克方法）：
- 时间窗口测试：「如果拖6个月，哪个选项会直接消失？」
- 删除测试：「如果一个选项被物理删除，你是如释重负还是怅然若失？」
- 使命压力测试：「如果这个选择成功了，你做的事对别人有用吗？」

后果阶梯（每条路径推三阶）：
路径A：
  一阶（3个月内）：{直接后果}
  二阶（6-12个月）：{连锁反应}
  三阶（1-3年）：{身份/关系/价值观级变化}

路径B：
  ...（同上）

★ 使命检查（新增——后果推演之后的价值观检验）：
推完了所有后果。在这个节点暂停，问一个不在矩阵里的问题：
「如果这件事做成，帮了多少人？帮了多深？」
- 总效用 = 帮助的人数 × 平均每人获得的帮助程度
- 如果答案是"只帮了我自己"——这不一定错，但要诚实面对
- 如果答案是一个很大的数字——那你承受的代价是否与这个数字匹配？
- 「如果失败了，你的工作对别人还有意义吗？别人能接过去继续推进吗？」

预验尸事故报告：
假设选了最优路径但3年后彻底失败。
失败原因TOP3：
1. {最可能原因} → 预防措施：{具体行动}
2. {次可能原因} → 预防措施：{具体行动}  
3. {第三可能原因} → 预防措施：{具体行动}

早期预警信号：
- 如果出现{X}，说明正在走向失败路径1
- 如果出现{Y}，说明需要调整策略
```

## 6. 判决 + 行动实验模板 ★

```
判决：进入 {X天/周 证据审判期 / 最小实验期}

理由：
1. {当前证据状况评估}
2. {为什么不是现在做不可逆决定}
3. {先试什么可以降低不确定性}

不可逆风险：
- {哪些一旦做了很难回头}
- {哪些代价即使失败也要承担}

★ 72小时行动实验（增强版——马斯克实验纪律）：
实验设计必须包含以下四个要素，缺一不可：

1. 锁定核心假设：
   「这个实验要验证的最核心假设是什么？」
   「如果这个假设是错的，你的整个判断还成立吗？」

2. 预设成功/失败标准（跑实验之前写下来！）：
   实验成功长什么样：{可观察、可测量的具体标准}
   实验失败长什么样：{同上}
   「原型就是证明。任何东西放到PPT里都能看起来不错。」

3. 最低成本执行（如果不是72小时，说明太复杂了）：
   「如果只给你3天和最低成本，你的第一个验证动作是什么？」
   - 动作1：{具体可执行的步骤，有时间、有数量}
   - 动作2：{同上}
   - 动作3：{同上}

4. 决策触发：
   对了→放大；错了→换方向。
   「不要花一个月做完美方案。花3天，跑一个实验，数据说话。」

复审条件：
- 如果证据支持{A}，升级行动到{具体步骤}
- 如果出现{B}信号，暂停并重新开庭
- 如果出现{C}危机，求助专业支持

本判决有效期：{具体时间}

★ 模式识别提示（新增——如果这不是第一次类似困惑）：
如果用户反复带来同一类困惑（如"第三次想辞职了"），提示：
「这不是一个需要审的决策，这是一个需要修复的系统。把你反复出现的这种纠结当成一个'产品'——它的用户是你自己，它的Bug是什么？只改一件事，你改什么？」
```
