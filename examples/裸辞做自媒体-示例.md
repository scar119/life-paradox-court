# 示例案件：我要不要裸辞做自媒体？

## 用户输入

```text
我要不要裸辞做自媒体？我现在工作很稳定，但每天都觉得没意思。
```

## 直觉宣誓

```text
我倾向想辞职，信心 65 分。
我最怕的是收入断掉，也怕父母觉得我不靠谱。
如果没人评价我，我会先试试自媒体。
我最想保住的是自由感，但也不想把生活搞崩。
```

## 理想输出摘要

```text
案件名称：现在的我诉稳定工作
争议焦点：你是在追求自由，还是在逃离被消耗的日常？

判决：进入 14 天证据审判期。

72 小时行动实验：
1. 先发布 3 条内容，而不是先辞职。
2. 记录发布耗时、互动反馈、能量消耗。
3. 三天后复审：你是更清醒，还是只是在逃避工作？

可分享判词：
你以为你怕失败，其实你怕验证自己到底有没有那么想要。
```
