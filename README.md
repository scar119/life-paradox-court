# 人生悖论审判庭

> 把你的困惑送上法庭。

这是一个游戏化哲学决策 Skill。用户输入一个真实人生困惑，系统会把它变成一场审判：立案、直觉宣誓、悖论关卡、哲学角色交锋、未来后悔模拟、判决书和 72 小时行动实验。

本项目是「繁星计划」黑客松教育赛道参赛作品，现以 MIT 许可证开源。

## 快速开始

**运行要求**：Python 3.8+，仅使用标准库，无需安装任何第三方依赖。

**配置模型**（可选，不配置则走内置模板兜底）：

```bash
export DEEPSEEK_API_KEY=你的密钥
```

启动可见前端：

```bash
./start-ui.sh
```

默认打开：

```text
http://127.0.0.1:8777/index.html
```

环境变量：

- `DEEPSEEK_API_KEY`：DeepSeek API 密钥。未设置时自动使用内置模板兜底，流程可完整走通但没有模型推理
- `DEEPSEEK_MODEL`：模型名称，默认 `deepseek-chat`
- `PARADOX_COURT_PORT`：修改端口，默认 `8777`
- `PARADOX_COURT_MODEL_TIMEOUT`：修改模型超时时间，默认 `180` 秒

如果未设置密钥或模型调用失败，系统会自动使用内置模板兜底，保证流程不中断。

## 典型演示

输入：

```text
我要不要裸辞做自媒体？我现在工作很稳定，但每天都觉得没意思。
```

系统会生成：

1. 案件档案：现在的我诉稳定工作
2. 直觉宣誓：记录当前倾向、恐惧和想保住的东西
3. 悖论关卡：未来后悔、体验机器、忒修斯之船等思想实验
4. 哲学家交锋：功利主义、康德主义、存在主义、卡尼曼、未来证人
5. 判决书：进入 14 天证据审判期
6. 可分享卡片：一句判词 + 哲学人格 + 行动实验，并生成可下载 PNG / SVG 图片

点击“开庭审判”后，系统不会直接摊开完整判决书，而是先显示开庭进度：复核案件材料、调取审判资料库、组装法庭提示词、哲学角色交锋、等待审判长落槌、生成分享判决卡。模型返回后，进入可点击推进的审判流程：

1. 立案陈词
2. 多个悖论关卡，每关都要写下“你的证词”
3. 哲学家交叉追问
4. 未来证人出庭
5. 最终判决
6. 行动实验说明与复审条件
7. 审判完成后生成信息图判决卡

第 6 步不是要求用户立刻离开页面做完实验再回来点击下一步，而是把最终判决转成可带走的 72 小时实验规则。真正执行和复审发生在页面之外。

完整判决书只在最后一幕后解锁。点击“审判完成”后，分享区会显示信息图卡片生成进度，完成后再出现 PNG / SVG 下载按钮和完整 Markdown 分享文案。想重新开始时，点击“新案件”，系统会清空当前本地会话的案件缓存、判决书、分享卡和日志，不会删除代码、资料库或示例。

## 为什么它是 Skill，而不是普通网页

它的核心不是界面，而是一套可复用流程：

- `角色库` 决定谁出庭
- `思想实验库` 决定用哪个关卡审问
- `审判模板` 决定每一步输出结构
- `边界规则` 决定哪些场景必须收束到专业求助或信息整理
- `server.py` 负责按案件阶段调度这些资料，并把 Markdown 卡片渲染成 1080×1440 的 SVG 分享图
- `app.js` 负责把长耗时审判过程呈现为可见进度，把判决书拆成逐步推进的互动审判流程，并在审判完成后显示信息图卡片生成进度，再把 SVG 判决卡转成 PNG 下载

未来扩展新角色、新思想实验、新判决风格，都可以直接改 `data/`。

## 边界

本 Skill 不提供医疗、法律、投资、心理危机等专业结论。遇到高风险主题，它只做事实整理、问题清单和求助流程。

## 参赛亮点

1. **有趣度强**：把人生困惑做成法庭游戏，而不是普通问答。
2. **记忆点强**：一句话可复述：“把你的困惑送上法庭。”
3. **结果可晒**：输出可预览、可下载的判决卡图片。
4. **资料库驱动**：不是提示词临场发挥，而是角色库、思想实验库、模板库共同调度。
5. **可商业化**：可扩展到职业选择、家庭沟通、亲密关系、成长决策、课程咨询等场景。
